# What to record, and how

Give the owner this checklist, filled in with their flows. A clip that breaks one of these
usually means re-recording, so it is worth the two minutes up front.

**Set-up**
- Record over a cable with QuickTime (File → New Movie Recording → pick the iPhone) for a clean
  status bar; the phone's own screen recorder adds a red dot. Android: `adb shell screenrecord`
  or the system recorder with demo mode on.
- Do Not Disturb on. Full battery or charging.
- A **demo account** with tidy data: no real names, emails, addresses, cards; no profanity or
  jokes in contact names, notes or activity; balances the owner is happy to show.
- If the flow needs a real payment or real money, make sure it will **succeed** on this device
  and account (e.g. a card valid in the store's region). A failed payment can't be the ending.

**Per flow**
- One recording per flow. Start on the home screen, finish on the result (and back home if
  the result shows up there).
- Move deliberately: pause about a second on every screen worth reading (review, confirmation).
- **Type** anything the story is about typing — AutoFill makes text appear in one jump.
- Record 2–3 seconds before the first tap and after the last screen.

**After**
- AirDrop or copy the files; tell Claude which file is which flow.
